# Machine-Learning-Projects
# Machine Learning Foundations: Regression, Trees, & Clustering

This repository contains a suite of Machine Learning projects focused on implementing and evaluating core algorithms. From predicting continuous variables to uncovering hidden structures in unlabeled data, these projects demonstrate a practical approach to the fundamental pillars of ML.

---

## 📂 Project Overview

The repository is divided into three primary modules, each focusing on a different learning paradigm:

### 1. Linear Regression (Supervised Learning)
Focused on predicting quantitative outcomes. This module covers data preprocessing, feature selection, and model evaluation using metrics like R-squared and Mean Squared Error (MSE).
* **Key Concepts:** Ordinary Least Squares, Gradient Descent, Overfitting vs. Underfitting.

### 2. Decision Trees (Supervised Learning)
A deep dive into non-linear classification and regression. This project demonstrates how logic-based models partition data to make decisions.
* **Key Concepts:** Entropy, Gini Impurity, Pruning, and Feature Importance.



### 3. K-Means & Clustering (Unsupervised Learning)
Exploration of pattern recognition without labeled outputs. This includes partitioning data into distinct groups based on feature similarity.
* **Key Concepts:** Centroid initialization, the Elbow Method for choosing $k$, and Silhouette Analysis.
